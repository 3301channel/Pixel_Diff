# 2026-08-12 开发修改记录

## 一、内存泄漏修复（5 处）

**文件**：`src/pixel_diff_api/task_service.py`、`src/pixel_diff_api/app.py`

| # | 问题 | 修复 |
|---|---|---|
| 1 | `_run_task` finally 块未清理 `_futures[task_id]`，Future 持有线程引用永不释放 | finally 中 `self._futures.pop(task_id, None)` |
| 2 | `ThreadPoolExecutor` 无 `shutdown()`，进程退出时线程泄漏 | 新增 `TaskManager.shutdown(wait=False)`，调用 `_executor.shutdown(cancel_futures=True)` + 清空 `_tasks`/`_futures` |
| 3 | `_tasks` 字典只增不减，长期运行 OOM | 新增定时清理线程（每 30 分钟），移除 completed/failed 超过 1 小时的旧任务内存缓存（磁盘数据保留） |
| 4 | FastAPI 无关闭钩子，uvicorn 退出时线程池未回收 | `@app.on_event("shutdown")` → `task_manager.shutdown()` |
| 5 | `_restore_from_disk` 回填旧任务到 `_tasks` 无 TTL | 由定时清理线程统一回收 |

**新增常量**：`_STALE_TASK_TTL = timedelta(hours=1)`

## 二、二值化自适应阈值修正

**文件**：`src/pixel_diff/models.py`

**问题**：PDF 抗锯齿文字经 `warpPerspective(INTER_LINEAR)` 多级对齐后，文字边缘灰化。`adaptiveThreshold(C=10)` 把灰化文字判为背景（白色），candidate 图中文字发白/消失。

**修复**：`adaptive_c: int = 10` → `5`

**实测效果**（同一对 PDF）：
| 指标 | 修复前 | 修复后 |
|---|---|---|
| candidate 暗像素 | 0.30% | 0.44% (+48.1%) |
| candidate 浅灰(180-250) | 82.8% | 2.6% (-97%) |

## 三、可配置渲染噪声过滤（三重保护）

**文件**：`src/pixel_diff/models.py`、`src/pixel_diff/engine.py`、`configs/sensitive_recall_trial.yaml`

### 3.1 新增配置项

```python
# models.py
min_significant_pixel_change: int = 100
"""区域中增加+删除像素的最小合计值，低于此视为渲染噪声并丢弃。"""
```

### 3.2 过滤逻辑（engine.py）

`classify_difference_regions` 之后插入：

```python
for r in regions:
    has_text = bool(r.template_text)       # 模板 PDF 有文字
    is_high  = (r.risk_level == "HIGH")    # 风险等级高
    is_big   = (added + deleted >= threshold)  # 像素变化大
    
    if has_text or is_high or is_big:
        keep(r)   # 三者任一成立 → 保留
    else:
        drop(r)   # 全不满足 → 丢弃（渲染噪声）
```

**设计原则**：宁可多保留，绝不漏杀。有模板文字或有 HIGH 风险等级的区域**绝不会**被过滤。

### 3.3 YAML 配置

```yaml
# configs/sensitive_recall_trial.yaml
min_significant_pixel_change: 2000  # API 默认使用此配置
```

**撤销方式**：YAML 中改为 `0` 或删除该行。

### 3.4 实测效果

| 文档对 | 过滤前 | 过滤后 | 漏报 |
|---|---|---|---|
| PDF_0 vs PDF_1（同内容不同渲染） | 250 | 4 (98.4%) | — |
| api_tasks（真实差异） | 8 | 8 | **0** |

## 五、配准质量检测增强

**文件**：`src/pixel_diff_api/task_service.py`

### 5.1 快速预检

在 CLI 命令行执行**之前**插入 `_quick_mismatch_check()`：
- 两份图 resize 到 256×256 → 灰度绝对差
- >20% 像素差异 >60 灰度值 → 直接 failed，不跑配准

### 5.2 三层短路条件

`_run_task` 解析 diff_result.json 后判定：

| 条件 | 阈值 | 含义 |
|---|---|---|
| `diff_rate > 50%` | 一半以上像素差异 | 内容大概率不同 |
| `inlier_ratio < 5%` | RANSAC 内点几乎为零 | 特征匹配彻底失败 |
| **`local_warp_gate_foreground_iou < 5%`** | 对齐后前景几乎不重合 | 配准本质失败 |

**注意**：报告模式下 `inlier_ratio` 在 `payload["pages"][0]` 而非 `payload["metrics"]`。
