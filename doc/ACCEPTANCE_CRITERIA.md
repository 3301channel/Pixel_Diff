# Pixel-Diff MVP 验收标准

## 1. 验收原则

验收必须基于冻结的数据、固定配置和可重复执行的脚本。不得以“肉眼看起来不错”作为通过依据。

全部 P0 条目通过，且不存在未关闭的阻断级缺陷，MVP 才可验收。P1 为推荐发布门槛；生产阶段能力不参与 MVP 判定。

## 2. 验收环境

- Python 3.11。
- OpenCV 与 NumPy 版本锁定于项目依赖文件。
- 单进程、CPU 模式；关闭调试日志。
- 标准性能机最低配置：4 个逻辑 CPU、8 GB 内存。
- 输入页为 A4、300 DPI，目标尺寸约为 `2480×3508`。
- 使用仓库中的默认配置，除非测试用例明确指定覆盖值。

验收报告必须记录操作系统、CPU、内存、Python、OpenCV、配置哈希和数据集版本。

## 3. 冻结验收数据集

数据集不得用于调参，并至少包含 100 对页面：

| 子集 | 数量 | 内容 |
|---|---:|---|
| 无正文变化 | 30 | 打印/扫描差异，可含轻微倾斜、缩放、灰度变化 |
| 明确正文变化 | 40 | 每页 1–5 处新增、删除或修改 |
| 彩色干扰 | 20 | 红章、蓝色签字或骑缝章，但正文不变 |
| 异常输入 | 10 | 错页、空白页、损坏文件、非图像文件、特征不足 |

正文变化由两名标注者独立绘制真值框；不一致部分经第三人确认。数据清单保存文件 SHA-256，验收后不得替换。

## 4. 匹配与指标定义

预测框与真值框的交并比：

```text
IoU = intersection_area / union_area
```

当预测框与真值框 `IoU ≥ 0.30`，或预测框覆盖真值框面积的比例 `≥ 0.70` 时，可形成一个匹配。使用一对一最大匹配，禁止一个预测框同时命中多个真值框。

```text
TP = 匹配成功的真值变化数
FN = 未被匹配的真值变化数
FP = 未匹配任何真值的预测区域数
Recall = TP / (TP + FN)
Precision = TP / (TP + FP)
```

多个相邻字符被合并为一个预测框时，只要该框覆盖对应的同一处人工标注变化，即视为一次命中。跨越两个无关变化的大框分别按一个 TP 和一个 FN 计。

## 5. P0 强制验收标准

### AC-P0-01 输入与渲染

- 支持读取有效 PNG、JPEG、TIFF 和 PDF 页面。
- PDF 按 `300 ± 1 DPI` 渲染。
- 30 个有效输入用例成功率为 100%。
- 路径不存在、文件损坏和格式不支持时，100% 返回 `InputError`，不得返回空差异冒充成功。

### AC-P0-02 配准能力

对正文相同、包含以下全局扰动的 20 对页面：

- 旋转：`-3°` 至 `+3°`。
- 平移：横纵方向各不超过页面尺寸的 5%。
- 等比缩放：95% 至 105%。

要求：

- 配准成功率 `≥ 95%`。
- 成功样本的人工校验控制点中位重投影误差 `≤ 2.0 px`。
- 95 分位重投影误差 `≤ 4.0 px`。
- 特征不足或错页的 10 个异常样本均须明确失败，不得崩溃。

### AC-P0-03 正文变化检出

在 40 页正文变化子集上：

- 区域召回率 `Recall ≥ 0.95`。
- 区域精确率 `Precision ≥ 0.85`。
- 每种变化类型（新增、删除、修改）召回率分别 `≥ 0.90`。
- 不允许出现导致整个页面无法处理的未捕获异常。

### AC-P0-04 无变化页误报

在 30 页无正文变化子集上：

- 至少 27 页输出零个差异区域，即页面零误报率 `≥ 90%`。
- 平均误报区域数 `≤ 0.20 个/页`。
- 任一误报框面积不得超过页面面积的 2%；超过即该项失败。

### AC-P0-05 彩色印章与签字抗干扰

在 20 页彩色干扰子集上，对比“关闭颜色过滤”和“开启颜色过滤”：

- 开启过滤后，由红章或蓝色签字造成的误报区域数量降低 `≥ 90%`。
- 至少 18 页不产生由彩色干扰导致的差异框。
- 在人工设置的黑色正文变化同时存在时，其召回率下降不得超过 2 个百分点。

### AC-P0-06 输出结构

对所有成功任务：

- JSON 可被标准解析器解析，成功率 100%。
- `id` 从 1 连续递增且无重复。
- 坐标均为整数并位于图像边界内。
- 区域顺序严格遵循 `y、x、面积降序`。
- 有差异时标注图成功写出，图像尺寸与模板一致，差异框数量与 JSON 数量一致。
- 无差异时返回空数组，不得使用 `null` 代替。

### AC-P0-07 参数与边界校验

以下非法参数均须在处理开始前返回 `ConfigurationError`：

- 非正 DPI。
- 小于等于 1 或为偶数的自适应窗口。
- 非正形态学核尺寸。
- `crop_margin < 0` 或不小于图像任一边长的一半。
- `min_diff_area < 0`。
- Lowe 比率不在 `(0, 1)`。

覆盖上述情况的自动化测试通过率为 100%。

### AC-P0-08 稳定性与确定性

- 对同一输入和配置连续运行 10 次，差异区域数量、顺序及全部坐标完全一致。
- 连续处理 100 页时进程不得崩溃，成功样本不得发生内存不足。
- 处理结束后，进程常驻内存相对第 10 页后的基线增长不超过 200 MB。

### AC-P0-09 自动化质量门

- 全部自动化测试通过。
- 核心包语句覆盖率 `≥ 90%`，分支覆盖率 `≥ 80%`。
- `ruff check` 零错误。
- `mypy` 对核心包零错误。
- 不存在高危或严重级别的已知依赖漏洞；若扫描器误报，必须有书面论证。

## 6. P1 推荐发布标准

### AC-P1-01 性能

在标准性能机上预热 3 次后，连续处理 30 张 A4、300 DPI 页面：

- 单页总耗时中位数 `≤ 2.0 s`。
- 单页总耗时 95 分位 `≤ 4.0 s`。
- 单任务峰值内存 `≤ 1.5 GB`。

PDF 渲染、配准、二值化、差分、形态学及区域提取必须分别记录耗时。

### AC-P1-02 可观测性与隐私

- 100% 的任务日志包含任务标识、阶段、耗时和最终状态。
- 失败日志包含异常类型和失败阶段。
- 扫描日志不得出现合同正文、图像二进制或 OCR 全文。
- 应用不得调用 `logging.basicConfig` 改变宿主程序日志配置。

### AC-P1-03 API 兼容性

- 返回结构符合规格文档示例及字段约束。
- 新增可选字段不得破坏旧调用方。
- 公共接口变更必须同步修改规格、验收测试和版本说明。

## 7. 失败判定

出现任一情况即判定验收失败：

- 任一 P0 条目未达到阈值。
- 测试过程更换样本、真值或默认配置而未重新冻结版本。
- 发生崩溃、死锁、静默吞错或将失败报告为“无差异”。
- 输出坐标越界，或结果无法追溯到输入、配置和软件版本。
- 把后续生产阶段能力作为 MVP 已实现能力对外承诺。

## 8. 验收证据

验收报告至少包含：

1. 数据集清单、版本和 SHA-256。
2. 运行环境与依赖版本。
3. 完整配置及其哈希。
4. 每页 TP、FP、FN、耗时和状态。
5. 聚合后的 Recall、Precision、零误报率和性能分位数。
6. 自动化测试、覆盖率、静态检查和依赖扫描结果。
7. 失败样本的输入标识、预测图、真值图和原因分析。

只有上述证据可由他人独立复算并得到同一结论时，验收结果才具备可论证性。
