# Pixel-Diff 系统规格文档

## 1. 范围与阶段

本文定义 Pixel-Diff 的 MVP 机制、接口、代码风格和测试内容。生产阶段扩展单独列出，不作为 MVP 已交付能力。

### 1.1 MVP 范围

输入为同一页的电子 PDF 或其标准渲染图，以及彩色扫描图；输出为差异区域列表、运行元数据和可选标注图。

### 1.2 非目标

- 不自动判定合同是否具有法律效力。
- 不保证识别黑色签名、铅笔痕迹或与正文同色的印章。
- 不在 MVP 中执行 OCR、语义比对或局部非线性校正。
- 不把排版、打印和纸张噪声全部视为正文篡改。

## 2. 核心机制

标准处理链如下：

```text
PDF/模板图 ─→ 300 DPI 渲染 ───────────────────────────┐
扫描图 ─→ 输入校验 ─→ HSV 过滤 ─→ 全局配准 ──────────┤
                                                       ↓
                 二值化 ─→ XOR 差分 ─→ 边缘裁剪
                                      ↓
                              形态学降噪
                                      ↓
                         连通域提取与面积过滤
                                      ↓
                         JSON 结果 + 可视化标注图
```

二值图中背景为 255、前景为 0。差异矩阵定义为：

```text
diff(x, y) = bin_scan(x, y) XOR bin_template(x, y)
```

值为 255 的像素表示两图在该位置的二值状态不同。

## 3. 模块规格

### 3.1 输入与渲染

- 接受 PDF 页面或 PNG/JPEG/TIFF 图像。
- PDF 默认渲染为 300 DPI、白色背景、BGR `uint8` 图像。
- 图像读取后校验：非空、宽高大于边缘裁剪的两倍、通道数受支持。
- 多页 PDF 在 MVP 中逐页调用；页数配对策略由调用方负责。

### 3.2 HSV 色彩过滤

- 将扫描图从 BGR 转为 HSV。
- 默认过滤红色区间 `[0,40,40]–[10,255,255]` 与 `[170,40,40]–[180,255,255]`。
- 默认过滤蓝色区间 `[100,40,40]–[124,255,255]`。
- 掩膜位置替换为白色 `[255,255,255]`。
- HSV 阈值必须可配置；过滤功能必须可关闭。

此机制仅降低彩色签章噪声，不代表识别签章语义。

### 3.3 全局图像配准

1. 将扫描图和模板图转为灰度图。
2. 使用 SIFT 提取关键点和描述子。
3. 使用 FLANN 进行 KNN 匹配，`k=2`。
4. 使用 Lowe 比率测试筛选匹配，默认阈值为 `0.70`。
5. 有效匹配点不得少于 15。
6. 使用 RANSAC 求取扫描图到模板图的单应性，默认重投影阈值为 3 像素。
7. 使用透视变换生成与模板同尺寸的对齐图。

描述子为空、匹配不足、单应性为空或数值非有限时，返回 `AlignmentError`，不得继续差分。

### 3.4 二值化

- 扫描图：灰度化后进行双边滤波，再使用高斯自适应阈值。
- 模板图：灰度化后使用 Otsu 阈值。
- 默认参数：双边滤波直径 9、颜色/空间 sigma 75；自适应窗口 21、常数 10。
- 自适应窗口必须是大于 1 的奇数。

### 3.5 差分与边缘裁剪

- 对尺寸相同的两张二值图执行逐像素 XOR。
- 将四边 `crop_margin` 范围置零；默认值 40 像素。
- 尺寸不一致时返回 `DimensionMismatchError`。

### 3.6 形态学处理

默认顺序和结构元素：

1. `3×3` 矩形核开运算，移除孤立噪声。
2. `3×3` 矩形核闭运算，填补局部空洞。
3. `15×10` 矩形核膨胀一次，将同一文本变化聚合为区域。

核尺寸和迭代次数均由配置控制。算法测试不得依赖模糊的视觉判断。

### 3.7 区域提取

- 使用外轮廓提取差异区域。
- 轮廓面积小于 `min_diff_area` 的区域被过滤；默认值为 150 像素。
- 每个保留区域输出外接矩形和轮廓面积。
- 区域必须裁剪到图像边界内并稳定排序。
- `id` 从 1 连续编号，编号发生在过滤和排序之后。

## 4. 公共接口

建议接口：

```python
result = engine.compare(
    scan_path="physical_signed_contract.png",
    template_path="approved_contract.pdf",
    page=0,
    visual_output_path="artifacts/result.png",
)
```

返回对象的 JSON 表示：

```json
{
  "status": "completed",
  "page": 0,
  "image": {"width": 2480, "height": 3508, "dpi": 300},
  "differences": [
    {
      "id": 1,
      "x": 420,
      "y": 860,
      "width": 135,
      "height": 42,
      "area": 3120.0
    }
  ],
  "metrics": {
    "elapsed_ms": 842,
    "good_matches": 126,
    "inlier_ratio": 0.91
  },
  "visual_output_path": "artifacts/result.png"
}
```

约束：

- `x、y、width、height` 为整数像素；`area` 为非负浮点数。
- 所有区域都满足 `0 ≤ x < image.width`、`0 ≤ y < image.height`。
- `x + width ≤ image.width`，`y + height ≤ image.height`。
- 无差异时 `differences` 是空数组；标注图可不生成，路径为 `null`。

## 5. 配置

至少提供以下配置项：

```yaml
dpi: 300
filter_colored_marks: true
sift_nfeatures: 10000
lowe_ratio: 0.70
min_good_matches: 15
ransac_reprojection_threshold: 3.0
crop_margin: 40
min_diff_area: 150
adaptive_block_size: 21
adaptive_c: 10
open_kernel: [3, 3]
close_kernel: [3, 3]
dilate_kernel: [15, 10]
```

配置在引擎创建时完成校验。非法配置返回 `ConfigurationError`。

## 6. 异常处理

领域异常至少包括：

- `InputError`：路径不存在、格式不支持、文件损坏或图像为空。
- `ConfigurationError`：阈值、核尺寸或裁剪范围非法。
- `AlignmentError`：特征不足、匹配不足或单应性求解失败。
- `DimensionMismatchError`：进入差分阶段的图像尺寸不同。
- `OutputError`：标注图或结果文件写出失败。

异常消息必须包含失败阶段和可操作原因，但不得泄露合同正文。

## 7. 日志与可观测性

- 使用模块级 logger，记录任务开始、阶段耗时、匹配点数量、内点比例、区域数量和失败阶段。
- 成功日志使用 INFO；可恢复诊断使用 WARNING；任务失败使用 ERROR。
- 不记录原始图像、合同文本或完整 OCR 内容。
- 性能计时使用单调时钟。

## 8. 代码风格

- 遵循 PEP 8；使用 `ruff` 进行静态检查和格式化。
- 公共接口使用完整类型标注；使用 `mypy` 检查核心包。
- 路径使用 `pathlib.Path`，配置与结果使用 `dataclass` 或校验模型。
- 函数保持单一职责；算法函数优先接收数组并返回数组或模型。
- 不修改调用方传入的图像数组，除非函数名和文档明确说明原地操作。
- 禁止裸 `except` 和吞异常；领域边界处包装异常并保留原始异常链。
- 注释解释“为什么”，名称和结构表达“做什么”。

## 9. 测试内容

- 单元测试：颜色掩膜、参数校验、二值化、裁边、形态学和区域排序。
- 集成测试：真实文件读取、PDF 渲染、配准、差分、JSON 和标注图输出。
- 验收测试：在冻结且人工标注的数据集上计算召回率、精确率、误报和耗时。
- 回归测试：每个线上或验收缺陷保留最小复现样本。

## 10. 生产阶段扩展

扩展按独立模块加入：

- `roi.py`：配置或版面模型生成忽略掩膜。
- `local_warp.py`：局部网格匹配和薄板样条变换。
- `stroke_normalization.py`：笔画宽度估计及模板补偿。
- `ocr.py`：仅对差异区域识别修改前后候选文本。

扩展不得改变现有结果坐标定义；新增字段应保持向后兼容。
